# Ambrosius’ 健身日誌 PWA

這是一套針對 iPhone 14 最佳化設計的個人漸進式 Web 應用程式 (PWA)。

## 部署至 GitHub Pages (免安裝軟體，3 分鐘完成)

1. 在 GitHub 建立一個公開的專案庫 (例如 `workout-pwa`)。
2. 點擊「Add file」>「Upload files」，將解壓縮後的 5 個檔案 (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) 全部上傳並 Commit。
3. 進入專案庫的 **Settings** > **Pages**，將 Branch 選為 `main`，點擊 **Save**。
4. 稍等約 1 分鐘，GitHub 會生成網址 (如 `https://<你的帳號>.github.io/workout-pwa/`)。
5. 用 iPhone 的 Safari 開啟該網址，點選下方「分享」按鈕，選擇「加入主畫面」即可。
